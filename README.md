# 會議紀錄管理系統

服務部的廠長會議、服務部會議紀錄整合在一起：會議總覽、會議總表、會議內容、組合條件查詢，以及新增／編輯會議紀錄。純前端網頁，不需要安裝資料庫，介面與「通報整合管理系統」相同。

## 同事觀看網址（GitHub Pages，公開網站）

https://cinnystar.github.io/yuxin-meeting/

推上 GitHub 後約 1 分鐘自動更新。網站是公開的：任何人拿到網址都看得到會議內容。在這個網址新增的會議只會存在觀看者自己的瀏覽器，正式新增請在本機開啟系統操作後推上 GitHub。

## 開啟方式

- 雙擊 `開啟系統.bat`：啟動本機伺服器並開啟瀏覽器（http://localhost:8791/）
- 或直接雙擊 `app\index.html`

## 功能

| 頁面 | 說明 |
|---|---|
| 會議總覽 | 會議總數、各類別場次、本月會議、待辦事項數；每月場次（依類別堆疊）；各類別最新一場會議的待辦事項；最新會議 |
| 會議總表 | 日期、時間、類別、主題、待辦數、附件；可搜尋、依月份篩選、排序、匯出 CSV |
| 會議內容 | 會議資訊、內容（待辦／決議／待釐清／摘要）、附件預覽；可編輯、列印、刪除 |
| 會議查詢 | 關鍵字（可只找主題或只找待辦事項）、會議類別、日期範圍、附件、出席者，任意組合 |
| 新增會議紀錄 | 填寫類別、日期、開始／結束時間、主題、出席者、內容、是否有附件（可上傳檔案） |

右上角的「類別」「年度」可切換只看廠長會議或服務部會議。

## 新增會議紀錄存到哪裡

- **連結系統資料夾（建議）**：在「新增會議紀錄」頁按「連結系統資料夾」，選擇本系統的 `app` 資料夾。之後儲存會直接寫入：
  - `app\data\meetings.js`（會議資料，每筆一行）
  - `app\會議紀錄\<年>\<會議編號>\`（附件）

  其他人重新整理網頁就能看到。需使用 Edge 或 Chrome；每次重新開啟瀏覽器時，第一次儲存會詢問是否允許寫入。
- **未連結時**：先存在這台電腦的瀏覽器（其他人看不到），頁面上方會提示「尚未寫入資料夾」，之後可按「寫入資料夾」一次補寫，或「下載 meetings.js」手動覆蓋。

## 會議內容格式

```
## 待辦事項
- 各廠長：11月13日內完成 CSI 好樣本數提升
## 決議事項
- 設備修繕與採購一律使用線上表單
  - 前面空兩格是子項目
## 會議摘要
### 小標題
- 內容
```

「待辦事項」段落的項目會顯示在會議總覽，也可在會議查詢中「只找待辦事項」。新增頁有「插入範本」按鈕。

## 更新到 GitHub

新增會議後，在此資料夾執行 `git add -A`、`git commit`、`git push`，或請 Claude 協助推上 GitHub。
